# F-19b: per-ABI release APKs named with the version, and the version in Settings

**Branch:** feat/f19b-abi-apks-and-version-label
**Goal:** `assembleRelease` produces one APK per CPU architecture plus a universal one, each named `monet-<versionName>-<abi>.apk`, and Settings shows the installed version.

## Context (read these first)
- `apps/android/app/build.gradle.kts`: `defaultConfig` already takes `versionName`/`versionCode` from `monetVersionName`/`monetVersionCode` (F-19a); `buildTypes.release` has `isMinifyEnabled = false`; `buildFeatures.buildConfig = true`, so `BuildConfig.VERSION_NAME` and `BuildConfig.VERSION_CODE` exist.
- `apps/android/app/src/main/java/dev/monet/app/feature/settings/SettingsScreen.kt`: the `SettingsScreen` composable; groups are built with `Group("TITLE") { ... }`; the last group is `DEVELOPER`.
- `apps/android/app/src/test/java/dev/monet/app/core/settings/SettingsMappingTest.kt`: the style of a plain JVM unit test in this project.
- `apps/android/CLAUDE.md`: Android area rules.

## Files to edit
- `apps/android/app/build.gradle.kts`: add ABI splits and the APK file name.
- `apps/android/app/src/main/java/dev/monet/app/core/settings/VersionLabel.kt`: NEW, the pure function `formatVersion`.
- `apps/android/app/src/test/java/dev/monet/app/core/settings/VersionLabelTest.kt`: NEW unit tests.
- `apps/android/app/src/main/java/dev/monet/app/feature/settings/SettingsScreen.kt`: show the label in a new `ABOUT` group.
- `docs/tasks/F-19b.md`: fill the Worker report section.

## Do not touch
Everything else, especially `contracts/openapi.yaml`, any `.env` or `local.properties` file, `MainActivity.kt`, `gradle/libs.versions.toml`, `docs/BACKLOG.md`, `docs/PROGRESS.md`, `docs/tasks/LESSONS.md`, and every existing test.

## Behaviour (decided by planner)
`VersionLabel.kt`, package `dev.monet.app.core.settings`: `fun formatVersion(name: String, code: Int): String`. Returns `"<name> (<code>)"`; when `name` is blank it uses `dev` as the name.
`SettingsScreen.kt`: add a last group after `DEVELOPER`, preceded by `HorizontalDivider(color = c.hairline)` like the other divider: `Group("ABOUT") { Text("Monet " + formatVersion(BuildConfig.VERSION_NAME, BuildConfig.VERSION_CODE), style = t.body, color = c.inkMuted) }`. Import `dev.monet.app.BuildConfig` and the function. Change nothing else in that file.
`build.gradle.kts`, inside the `android { ... }` block, add:
- `splits { abi { isEnable = true; reset(); include("arm64-v8a", "armeabi-v7a", "x86_64"); isUniversalApk = true } }`
- After it, rename every output of every variant so the file is `monet-<versionName>-<abi>.apk`, where `<abi>` is the output's ABI filter (`arm64-v8a`, `armeabi-v7a`, `x86_64`) or `universal` when the output has no ABI filter. Use `applicationVariants.all { outputs.all { (this as com.android.build.gradle.internal.api.BaseVariantOutputImpl).outputFileName = ... } }` and take `versionName` from `monetVersionName`. If that API does not compile with the installed AGP, report it in the Worker report as a blocker instead of inventing another approach.
- Do not enable R8/minify, signing or anything else (those are F-19c and a later task).
