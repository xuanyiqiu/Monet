# F-19a: APK version computed from git

**Branch:** feat/f19a-version-from-git
**Goal:** Every APK carries a `versionName` taken from the latest git tag and a `versionCode` that grows with every commit, so installs can upgrade in place and a bug report can be traced to a commit.

## Behaviour (decided by planner)
At the top of `app/build.gradle.kts`, after the `localProps` block, add a function `gitOutput(vararg args: String): String?` that runs `git <args>` with `providers.exec`, working directory `rootProject.projectDir`, `isIgnoreExitValue = true`, and returns the trimmed standard output, or `null` when the exit value is not 0, the output is empty, or git cannot be started (wrap the call in `try/catch (e: Exception)`).
Then define two top-level values:
- `val monetVersionCode: Int` = the Gradle property `monet.versionCode` converted with `toInt()` when present; otherwise `gitOutput("rev-list", "--count", "HEAD")?.toIntOrNull()`; otherwise `1`.
- `val monetVersionName: String` = the Gradle property `monet.versionName` when present; otherwise `gitOutput("describe", "--tags", "--match", "v[0-9]*", "--dirty=-dirty")` with one leading `v` removed; otherwise `"0.1.0-dev"`.
Read properties with `providers.gradleProperty("monet.versionCode").orNull`; a property whose value is blank counts as absent (`takeIf { it.isNotBlank() }`). Git output is never trimmed of anything except surrounding whitespace, and only a single leading `v` is removed with `removePrefix("v")`; the property value for `monet.versionName` is used as given. Stderr noise from git (for example "fatal: No names found") is expected when there are no tags and is ignored. If `providers` is not resolvable inside the function, use `project.providers`.
In `defaultConfig` replace the two hard-coded lines with `versionCode = monetVersionCode` and `versionName = monetVersionName`.
Register a task at the end of the file: `tasks.register("printVersion") { doLast { println("monet-version $monetVersionName $monetVersionCode") } }`.
Nothing else changes: no signing, no R8, no splits (those are F-19b and F-19c).
