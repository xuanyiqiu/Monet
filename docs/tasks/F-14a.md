## Tests (7 test functions in the new file; every request uses `AnnotateRequest(text = "画蛇添足", targetLang = Lang.EN, depth = Depth.FULL)` unless a test says otherwise, because `FakeMonetApi` returns a non-empty translation only for its three sample texts, and the cache does not store empty ones; JUnit4 + `runBlocking`; a `TemporaryFolder` rule for the cache folder; a counting delegate is `object : MonetApi by FakeMonetApi(latencyMs = 0) { override suspend fun annotate(request: AnnotateRequest): Annotation { calls++; ... } }`, adapting to the real `FakeMonetApi` constructor)
1. `put` then `get` for the same text, target and depth returns the annotation with `cached == true`; `get` with another target language returns `null`.
2. `put` of an annotation whose `translation` is empty is not stored (`get` returns `null`).
3. With `maxEntries = 2` and a clock that returns 1_000_000, 2_000_000, 3_000_000 on successive `put` calls (large distinct values, because eviction sorts by file timestamp), after three puts of different texts the first text is gone and the other two remain.
4. `cacheKey(" abc ", Lang.ZH, Depth.FAST) == cacheKey("abc", Lang.ZH, Depth.FAST)` and it differs from the same text with `Lang.EN`, and from `Depth.FULL`.
5. `CachingMonetApi`: two `annotate` calls with the same request reach the delegate once (counter equals 1) and both return the same translation.
6. Stale fallback: a cache with a mutable clock variable, `CachingMonetApi(delegate, cache, freshForMs = 500)`; the delegate answers the first call and throws `ApiException(problem = null)` afterwards. Call 1 stores the answer, then advance the clock by 10_000 ms, then call 2 returns the stored annotation instead of throwing.
7. Empty cache: a delegate that always throws `ApiException(problem = null)` makes `annotate` rethrow that `ApiException`.
