## Tests (8 test functions, new file `NotebookTest.kt`; every comparison of a `Double` uses `assertEquals(expected, actual, 1e-9)`; JUnit4; build an `Annotation` from the fake API as described above; a fixed entry is `NotebookEntry(id = "x", savedAt = 0, annotation = a, dueAt = 0)`; `now` is a plain `Long` you choose, for example `1_000_000_000L`; `DAY` is `24L * 60 * 60 * 1000`)
1. `review(entry, Grade.GOOD, now)` on a new entry gives `intervalDays == 1`, `dueAt == now + DAY`, `ease == 2.5`, `reviews == 1`, `lapses == 0`.
2. `review(entry, Grade.EASY, now)` on a new entry gives `intervalDays == 3` and `ease == 2.65` (compare doubles with a delta of 1e-9).
3. `review(entry, Grade.AGAIN, now)` gives `dueAt == now + 10 * 60 * 1000`, `intervalDays == 0`, `ease == 2.3` (delta 1e-9), `lapses == 1`; and applying `AGAIN` eight times in a row never takes `ease` below `1.3`. This is ONE test function with both checks.
4. Three `GOOD` reviews in a row, each applied to the previous result, give the intervals 1, 3 and 8 (3 x 2.5 = 7.5 rounds to 8).
5. `dueEntries(entries, now, limit = 2)` over four entries with `dueAt` values `now - 3`, `now - 1`, `now`, `now + 1` returns the two most overdue entries in that order and never the future one; with `limit = 10` it returns the three that are due.
6. `searchNotebook` on one entry whose annotation is `a.copy(text = "Hello World", translation = "Greeting", expressions = listOf(a.expressions[0].copy(text = "Zebra Crossing", meaning = "pedestrian")))` (Latin text, because Chinese has no letter case): the queries `hello`, `GREET`, `zebra` and `PEDESTRIAN` each return that entry; a blank query returns every entry in the list; `qqq` returns an empty list.
7. Repository round trip with a `TemporaryFolder` file and a fixed clock (take the id from `val id = repo.save(a).id`, which is the notebook id such as `EN:...`, not `a.id`): `save(a)` twice leaves one entry (same id); a second `NotebookRepository` on the same file, after `load()`, has the same entries; `grade(id, Grade.GOOD)` is visible in a third repository after `load()`; `remove(id)` leaves an empty list that a fourth repository also reads as empty.
8. A notebook file containing the text `not json`: `load()` yields an empty list and the file is renamed to `notebook.json.corrupt` (use the file name you gave the repository plus `.corrupt`), and a following `save(a)` works.
