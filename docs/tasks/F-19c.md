# F-19c: sign release APKs with the local keystore

**Branch:** feat/f19c-release-signing
**Goal:** `assembleRelease` produces APKs signed with the release key kept outside git, and `scripts/release_android.ps1` builds them from a clean state and writes SHA-256 checksums.

## Context (read these first)
- `apps/android/app/build.gradle.kts`: has `localProps` (reads `apps/android/local.properties`), `monetVersionName`, the `buildTypes.release` block (`isMinifyEnabled = false`), the ABI `splits` and the release output rename (F-19b).
- `apps/android/local.properties` is git-ignored and already holds four keys: `monet.release.storeFile`, `monet.release.keyAlias`, `monet.release.storePassword`, `monet.release.keyPassword`. You must NOT read or print that file: use the property names only.
- `scripts/lane.ps1`: the style of a PowerShell script in this repo (`$ErrorActionPreference = "Stop"`, header comment with usage).

## Files to edit
- `apps/android/app/build.gradle.kts`: add `signingConfigs`, attach it to the release build type, add the `printSigning` task.
- `scripts/release_android.ps1`: NEW release script.
- `docs/tasks/F-19c.md`: fill the Worker report section.

## Behaviour (decided by planner)
`build.gradle.kts`:
- A helper `fun signingProp(name: String): String?` placed after `gitOutput`: returns `providers.gradleProperty(name).orNull` when that property exists (even if blank), otherwise `localProps.getProperty(name)`; a blank result becomes `null` (`takeIf { !it.isNullOrBlank() }`).
- `val releaseStoreFile = signingProp("monet.release.storeFile")`. When it is not null and `file(it).exists()` is false, throw `GradleException("Release keystore not found: $it")` (fail loudly; never silently build unsigned when a path was given).
- When `releaseStoreFile` is not null: in `android { signingConfigs { create("release") { ... } } }` set `storeFile = file(releaseStoreFile)`, `storePassword = signingProp("monet.release.storePassword")`, `keyAlias = signingProp("monet.release.keyAlias")`, `keyPassword = signingProp("monet.release.keyPassword")`; and in `buildTypes.release` set `signingConfig = signingConfigs.getByName("release")`. When it is null, no signing config is created and release stays unsigned (a fresh clone must still build).
- Never print any password or the keystore path in logs.
- Register `tasks.register("printSigning") { doLast { println("monet-signing ${releaseStoreFile != null}") } }`.
`scripts/release_android.ps1` (header comment with usage; `$ErrorActionPreference = "Stop"`; paths computed from `$PSScriptRoot`):
1. Refuse to run when `git status --porcelain` is not empty, with the message `Working tree is not clean; commit first.`.
2. Run `./gradlew.bat clean assembleRelease` with the working directory `apps/android`, and stop when the exit code is not 0.
3. Find `apksigner.bat` under `$env:ANDROID_HOME\build-tools\*\apksigner.bat` (newest folder) and run `apksigner.bat verify --print-certs <apk>` for every `.apk` in `apps/android/app/build/outputs/apk/release`; stop with `Unsigned or invalid APK: <name>` when a verify fails.
4. Write `SHA256SUMS.txt` in that folder with one line per APK: `<lowercase hash>  <file name>` using `Get-FileHash -Algorithm SHA256`.
5. Print each APK name with its size in MB, and the final line `Release OK: <versionName from the first APK name>`.

## Tests (commands and exact expected output; working directory `apps/android`; quote every `-P` argument)
1. `./gradlew.bat -q :app:printSigning` prints exactly `monet-signing true`.
2. `./gradlew.bat -q :app:printSigning "-Pmonet.release.storeFile="` prints exactly `monet-signing false`.
3. `./gradlew.bat -q :app:printSigning "-Pmonet.release.storeFile=D:/nope/missing-store.p12"` fails with a non-zero exit and the output contains `Release keystore not found`.
4. `./gradlew.bat testDebugUnitTest lintDebug assembleDebug` is green.
