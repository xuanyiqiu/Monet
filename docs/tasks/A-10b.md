## Behaviour (decided by planner)
- `_url(key)` keeps the existing validation (`..` or leading `/` raises `ValueError("invalid blob key")`), then builds the path with `urllib.parse.quote(key, safe="/")`. Slashes stay as separators; every other reserved character is percent-encoded, including a literal `%` (it becomes `%25`; this is correct). Import `quote` at the top of the file.
- `aclose()` uses `self._http` directly (never `self._client()`, which would create a client just to close it). If `self._http` is `None`, it does nothing. If the client exists and `is_closed` is `False`, it awaits `aclose()` on it. It does not reset `_http`; a store is not reusable after `aclose()` (say so in the docstring).
- `SupabaseBlobStore` owns its client even when one was injected.
- In `lifespan`, after `await app.state.documents.join()` and before the engine dispose, close the blob store: `closer = getattr(app.state.documents.blobs, "aclose", None)`; if it is not `None`, `await closer()`. Plain sequential code: no `try/finally` (out of scope). `LocalBlobStore` has no `aclose`, so nothing happens for it.
- Do not add `aclose` to the `BlobStore` Protocol and do not add it to `LocalBlobStore`.

## Tests
SAFETY for tests 5 and 6: the environment may define `MONET_DATABASE_URL` or `MONET_SUPABASE_*`. Build the settings as `settings.model_copy(update={"database_url": None, "supabase_url": None, "supabase_service_key": None})` and pass that to `create_app`. Never let a test open a real database.

1. `put("user@x.com/a b.pdf", b"x")` sends a request whose `request.url.raw_path.decode()` equals `/storage/v1/object/documents/user%40x.com/a%20b.pdf`.
2. `put("100%.pdf", b"x")` sends `raw_path` `/storage/v1/object/documents/100%25.pdf`.
3. Key `"a b/ü.pdf"`: `put` then `get` returns the same bytes (the mock handler reads the already-decoded `request.url.path`).
4. A store created with no injected client (`SupabaseBlobStore("https://p.supabase.co", SERVICE_KEY)`) accepts `await store.aclose()` without error and `store._http` is still `None` afterwards (no client was created just to close it). Then the injected-client case: `make_store({})`, call `aclose()` twice, no error, and the injected client's `is_closed` is `True`.
5. Lifespan closes the store: `app = create_app(safe_settings, llm=fake_llm)`; replace `app.state.documents.blobs` with a `make_store({})` instance; keep `client = store._http`; run `with TestClient(app):` and leave it; afterwards `client.is_closed` is `True`. (The store `create_app` built is a `LocalBlobStore` because the safe settings have no Supabase values, so replacing it leaks nothing.)
6. Regression guard (passes before and after the change, that is intended): `with TestClient(create_app(safe_settings, llm=fake_llm)):` enters and exits without any exception using the default `LocalBlobStore`.
