## Behaviour (decided by planner)
- `_url(key)` keeps the existing validation (`..` or leading `/` raises `ValueError("invalid blob key")`), then builds the path with `urllib.parse.quote(key, safe="/")`. Slashes stay as separators; every other reserved character is percent-encoded. Import `quote` at the top of the file.
- `SupabaseBlobStore` owns its HTTP client even when one was injected: `aclose()` closes it. After closing, `aclose()` can be called again without error (check `client.is_closed` before closing).
- In `lifespan`, after `await app.state.documents.join()` and before the engine dispose, close the blob store: `closer = getattr(app.state.documents.blobs, "aclose", None)`; if it is not `None`, `await closer()`. `LocalBlobStore` has no `aclose`, so nothing happens for it.
- Do not add `aclose` to the `BlobStore` Protocol and do not add it to `LocalBlobStore`.

## Tests
1. `put("user@x.com/a b.pdf", b"x")` sends a request whose `request.url.raw_path.decode()` equals `/storage/v1/object/documents/user%40x.com/a%20b.pdf`.
2. Key `"a b/ü.pdf"`: `put` then `get` returns the same bytes (the mock decodes `request.url.path`, so the round trip must work).
3. `aclose()` called twice on a store built with `make_store(...)` does not raise, and the injected client's `is_closed` is `True`.
4. Lifespan closes the store: build `app = create_app(settings, llm=fake_llm)`, replace `app.state.documents.blobs` with a `make_store({})` instance, run `with TestClient(app):` and leave it; afterwards the store's client `is_closed` is `True`. Keep a reference to the client (`store._http`) before the `with` block.
5. Lifespan with the default `LocalBlobStore`: `with TestClient(create_app(settings, llm=fake_llm)):` enters and exits without any exception.
